## 13.2 異步任務系統

### 設計理念

計算密集操作（回測、優化、組合分析）不阻塞 HTTP 請求，通過異步任務隊列處理。

### 工作流程

```
客戶端 POST 請求
    ↓
API 層創建任務 → 返回 task_id
    ↓
TaskManager 提交到 ThreadPoolExecutor
    ↓
後台執行 → 更新進度 → WebSocket 廣播
    ↓
客戶端輪詢 GET /api/tasks/{id} 或接收 WebSocket 推送
```

### 任務類型（14 種）

| 類型 | 說明 | 重量級 |
|------|------|--------|
| `backtest` | 基礎回測 | ✓ |
| `backtest_advanced` | 高級回測 | ✓ |
| `backtest_multi` | 多策略回測 | ✓ |
| `optimize` | 參數優化 | ✓ |
| `portfolio` | 組合分析 | ✓ |
| `walkforward` | Walk-Forward | ✓ |
| `auto_optimize` | 全自動優化 | ✓ |
| `stock_universe_sync` | 股票池同步 | |
| `stock_universe_intro` | 股票簡介同步 | |
| `data_download` | 數據下載 | |
| `data_download_all` | 批量下載 | ✓ |
| `data_incremental` | 增量更新 | |

### 去重機制

通過 `(task_type, params_hash)` 去重，避免重複提交相同參數的任務。

### 取消機制

協作式取消：任務在關鍵檢查點調用 `is_cancelled()`，如果已取消則提前退出。

### 計算預算管理

`compute_budget.py` 根據當前運行的重量級任務數動態分配 CPU 核心數，防止資源爆炸。

## 13.3 三層緩存

```
┌─────────────────────────────────┐
│  Layer 1: 進程內 LRU Cache      │
│  - K 線數據 @lru_cache          │
│  - 最快，但進程重啟丟失          │
├─────────────────────────────────┤
│  Layer 2: Redis Cache           │
│  - CacheManager 統一接口        │
│  - LRU Fallback（1000 條目）     │
│  - 雙寫模式                     │
├─────────────────────────────────┤
│  Layer 3: 結果緩存              │
│  - result_cache.py              │
│  - 數據版本感知自動失效          │
│  - TTL: 回測30min/優化2h/組合1h │
└─────────────────────────────────┘
```

### 數據版本感知

結果緩存的 key 包含數據版本 hash，當 K 線數據更新時，相關的回測/優化結果自動失效。

## 13.4 多數據源容錯

### 熔斷器模式

```python
class CircuitBreaker:
    failure_threshold = 5      # 連續失敗次數
    recovery_timeout = 300     # 冷卻時間（秒）
    
    def call(self, func):
        if self.is_open:
            if time.time() - self.last_failure > self.recovery_timeout:
                self.half_open()
            else:
                raise CircuitOpen()
        try:
            result = func()
            self.record_success()
            return result
        except Exception as e:
            self.record_failure()
            raise
```

### 降級鏈

```
Yahoo Finance → AKShare → 新浪 → 騰訊 → 東財
```

每層失敗自動切換到下一層，用戶無感知。

## 13.5 認證與授權

### JWT 認證流程

```
1. 客戶端 POST /api/auth/login (username, password)
2. 服務端驗證 bcrypt 密碼哈希
3. 生成 JWT Token (HS256, 24h 有效期)
4. 返回 Token
5. 客戶端後續請求攜帶 Authorization: Bearer <token>
6. 中間件驗證 Token 有效性
```

### 權限模型

| 角色 | 能力 |
|------|------|
| 匿名 | 讀取公開端點（演示模式） |
| 用戶 | 執行回測、優化、管理自選股、設置預警 |
| 管理員 | 用戶管理、配置修改、股票池同步 |

### 中間件白名單

部分 GET 端點免認證：健康檢查、配置讀取、儀表盤、實時行情、板塊數據、預警歷史、基準指數等。

## 13.6 速率限制

### 滑動窗口算法

```python
class RateLimiter:
    def __init__(self):
        self.windows = {}  # IP -> [timestamps]
        self.max_entries = 10000  # LRU 淘汰
    
    def check(self, ip, limit=120, window=60):
        now = time.time()
        # 清理過期記錄
        self.windows[ip] = [t for t in self.windows[ip] if now - t < window]
        if len(self.windows[ip]) >= limit:
            return False
        self.windows[ip].append(now)
        return True
```

- 通用端點：120 請求/分鐘
- 認證端點：10 請求/分鐘
- 最大追蹤 10,000 個 IP（LRU 淘汰）

## 13.8 用戶策略沙箱

### AST 安全檢查

```python
import ast

class StrategyChecker(ast.NodeVisitor):
    BLOCKED_MODULES = {'os', 'sys', 'subprocess', 'socket', 'requests'}
    BLOCKED_BUILTINS = {'eval', 'exec', '__import__', 'open', 'compile'}
    
    def visit_Import(self, node):
        for alias in node.names:
            if alias.name.split('.')[0] in self.BLOCKED_MODULES:
                raise SecurityError(f"Blocked module: {alias.name}")
    
    def visit_Call(self, node):
        if isinstance(node.func, ast.Name):
            if node.func.id in self.BLOCKED_BUILTINS:
                raise SecurityError(f"Blocked builtin: {node.func.id}")
```

## 13.9 數據庫設計原則

- **WAL 模式**：讀寫並發，寫入不阻塞讀取
- **PRAGMA 調優**：大緩存、內存映射、合理超時
- **版本化遷移**：確保 Schema 升級的原子性和可追溯性
- **線程本地連接**：每個線程獨立連接，避免鎖競爭
- **JSON 字段**：靈活存儲結構化數據（策略參數、用戶設置等）

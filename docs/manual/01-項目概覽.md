# 1. 項目概覽

## 1.1 簡介

Stock-Quant 是一個生產級的 **A 股量化回測 + 實時盯盤預警系統**。系統以 Yahoo Finance 為主數據源，AKShare 為備選，SQLite 本地存儲，FastAPI 提供 Web 服務。

**核心能力**：
- 📊 **量化回測**：30 種內置策略，支持 A 股漲跌停/T+1 規則、滑點模擬、多維度風險指標
- 🔬 **參數優化**：網格搜索 + Optuna 貝葉斯優化，Walk-Forward 前進分析
- 📈 **組合分析**：18+ 種投資組合構建方法（風險平價/MVO/BL/HRP/CVaR 等）
- 🔔 **實時信號與預警**：30 策略並行計算信號強度，多渠道通知（企微/釘釘/Telegram）
- 🛡️ **風控系統**：倉位管理、風險預算、回撤保護、模擬交易
- 🖥️ **雙入口**：Web UI（SPA）+ CLI 命令行

## 1.2 技術棧

| 層次 | 技術 |
|------|------|
| 語言 | Python 3.11+（推薦 3.12） |
| Web 框架 | FastAPI 0.115+ + Uvicorn |
| 數據庫 | SQLite（WAL 模式），可選 Redis 緩存 |
| 回測引擎 | Backtrader |
| 配置管理 | pydantic-settings（`SQ_` 前綴環境變量） |
| 數據源 | Yahoo Finance（主）、AKShare（備）、Binance、Frankfurter |
| 參數優化 | Optuna（貝葉斯）+ 網格搜索 |
| 定時任務 | APScheduler |
| 認證 | PyJWT + bcrypt |
| 前端 | 原生 JavaScript（無 npm/node）+ Chart.js + ECharts + Lightweight Charts |
| 容器化 | Docker 多階段構建 + Docker Compose |
| CI/CD | GitHub Actions（pytest + Docker 構建 + Render 自動部署） |
| MCP | Model Context Protocol stdio server |
| 測試 | pytest + Playwright（可選） |

## 1.5 關鍵設計決策

| 決策 | 原因 |
|------|------|
| SQLite 而非 PostgreSQL | 單機部署場景，WAL 模式 + PRAGMA 調優滿足性能需求 |
| Backtrader 作為回測引擎 | 成熟的 Python 回測框架，社區活躍 |
| 三層緩存 | 進程內 LRU → Redis → 結果緩存（數據版本感知自動失效） |
| AST 沙箱 | 用戶上傳策略時通過 AST 解析阻止危險模塊導入 |
| 多數據源容錯 | 每個數據接口 2-3 個備選源，熔斷器自動降級 |
| 任務去重 | (task_type, params_hash) 去重避免重複計算 |
| 前端無構建鏈 | 純原生 JS + CDN，降低部署複雜度 |
| SQ_ 環境變量前綴 | 避免與其他應用的環境變量衝突 |

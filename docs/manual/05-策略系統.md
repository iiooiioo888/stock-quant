## 5.3 自定義策略開發

### 基本結構

用戶可在 `strategies/` 目錄下創建 `.py` 文件，繼承 `UserStrategy` 基類：

```python
from src.core.strategy_base import UserStrategy

class MyStrategy(UserStrategy):
    name = "my_strategy"
    description = "我的自定義策略"
    params = {
        "lookback": {"default": 20, "min": 5, "max": 100, "step": 5},
        "threshold": {"default": 0.05, "min": 0.01, "max": 0.2, "step": 0.01},
    }

    def buy_signal(self, df):
        """
        買入信號邏輯
        
        Args:
            df: DataFrame，包含 open/high/low/close/volume 列
        Returns:
            bool: True 表示買入信號
        """
        ma = df['close'].rolling(self.params['lookback']).mean()
        return df['close'].iloc[-1] > ma.iloc[-1] * (1 + self.params['threshold'])

    def sell_signal(self, df):
        """
        賣出信號邏輯
        
        Args:
            df: DataFrame
        Returns:
            bool: True 表示賣出信號
        """
        ma = df['close'].rolling(self.params['lookback']).mean()
        return df['close'].iloc[-1] < ma.iloc[-1]
```

### 安全沙箱

系統使用 AST 解析檢查策略代碼，阻止以下危險操作：
- `import os`, `import sys`, `import subprocess`
- `eval()`, `exec()`, `__import__()`
- 文件系統操作（`open`, `read`, `write`）
- 網絡操作（`socket`, `requests`）

### 自動轉換

`strategy_base.py` 的 `to_backtrader()` 方法會自動將用戶策略轉換為 Backtrader 策略類，無需手動編寫 Backtrader 代碼。

### 使用自定義策略

```bash
# CLI
python main.py backtest --code 600519 --strategy my_strategy

# Web API
POST /api/backtest
{
  "code": "600519",
  "strategy": "my_strategy",
  "params": {"lookback": 30, "threshold": 0.08}
}
```

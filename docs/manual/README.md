## 系統一句話描述

Stock-Quant 是一個 **A 股量化回測 + 實時盯盤預警系統**，支持 19 種內置策略、13+ 組合分析方法、多市場行情（A 股/港股/美股/加密貨幣/外匯/Polymarket 預測市場），提供 Web UI 和 CLI 雙入口，可 Docker 一鍵部署。

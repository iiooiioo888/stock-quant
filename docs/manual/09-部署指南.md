# 9. 部署指南

## 9.1 本地部署

### 最簡方式

```bash
pip install -r requirements.txt
python main.py serve
```

### 開發模式

```bash
pip install -r requirements.txt -r requirements-dev.txt
python main.py serve --reload  # 熱重載（需 uvicorn[standard]）
```

## 9.2 Docker 部署

### Dockerfile

多階段構建，基於 Python 3.12-slim：

```dockerfile
# Builder 階段
FROM python:3.12-slim AS builder
COPY requirements.txt .
RUN pip install --no-cache-dir --prefix=/install -r requirements.txt

# Runtime 階段
FROM python:3.12-slim
COPY --from=builder /install /usr/local
RUN useradd -m appuser
USER appuser
ENTRYPOINT ["tini", "--"]
CMD ["python", "main.py", "serve", "--host", "0.0.0.0"]
```

特點：
- 使用 tini 作為 PID 1（正確處理信號）
- 非 root 用戶運行
- 多階段構建減小鏡像體積

### Docker Compose

```yaml
services:
  app:
    build: .
    ports:
      - "8000:8000"
    environment:
      - SQ_DEMO_MODE=true
    volumes:
      - ./data:/app/data

  redis:
    image: redis:7-alpine
    command: redis-server --maxmemory 256mb --maxmemory-policy allkeys-lru
    volumes:
      - redis-data:/data

  nginx:  # 可選，需 --profile nginx
    image: nginx:alpine
    ports:
      - "80:80"
    profiles:
      - nginx
```

### 啟動命令

```bash
# 基本啟動（App + Redis）
docker compose up -d

# 含 Nginx 反向代理
docker compose --profile nginx up -d

# 查看日誌
docker compose logs -f app

# 停止
docker compose down
```

## 9.3 Nginx 配置

`nginx.conf` 提供：

- **反向代理**：將 HTTP 請求轉發到 FastAPI
- **WebSocket 代理**：`/ws` 路徑的升級代理
- **速率限制**：API 10r/s，WebSocket 5r/s
- **Gzip 壓縮**：減少傳輸大小
- **安全頭**：X-Frame-Options, X-Content-Type-Options 等

## 9.4 Render.com 部署

### `render.yaml` 配置

```yaml
services:
  - type: web
    name: stock-quant
    runtime: python
    buildCommand: pip install -r requirements.txt
    startCommand: python main.py serve --host 0.0.0.0 --port $PORT
    plan: free
    region: singapore
    envVars:
      - key: SQ_DEMO_MODE
        value: "true"
      - key: SQ_REDIS_ENABLED
        value: "false"
```

### 自動部署

GitHub Actions 在 push to main 時自動觸發 Render 部署：

```yaml
# .github/workflows/deploy.yml
name: Deploy to Render
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Trigger Render deploy
        run: |
          curl -X POST "https://api.render.com/v1/services/${{ secrets.RENDER_SERVICE_ID }}/deploys" \
            -H "Authorization: Bearer ${{ secrets.RENDER_API_KEY }}"
```

## 9.5 CI/CD

### GitHub Actions (`ci.yml`)

```yaml
name: CI
on: [push, pull_request]
jobs:
  test:
    strategy:
      matrix:
        python-version: ["3.11", "3.12"]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python-version }}
      - run: pip install -r requirements.txt -r requirements-dev.txt
      - run: pytest tests/ -v

  docker:
    needs: test
    steps:
      - uses: actions/checkout@v4
      - run: docker build -t stock-quant .
      - run: docker run -d -p 8000:8000 stock-quant
      - run: |
          for i in $(seq 1 30); do
            curl -sf http://localhost:8000/api/health && exit 0
            sleep 2
          done
          exit 1
```

## 9.6 環境變量配置

### 生產環境建議

```env
# .env
SQ_DEMO_MODE=false
SQ_HOST=0.0.0.0
SQ_PORT=8000
SQ_REDIS_ENABLED=true
SQ_REDIS_URL=redis://localhost:6379
SQ_WORKERS=4
SQ_CORS_ORIGINS=https://your-domain.com
SQ_WEBHOOK_URL=https://your-webhook-url
SQ_WECHAT_WEBHOOK=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx
```

### 安全注意事項

- JWT Secret 自動生成並持久化到 `data/.jwt_secret`
- 首次啟動時自動生成管理員密碼（見日誌）
- 生產環境務必設置 `SQ_DEMO_MODE=false`
- 配置 CORS 允許的來源域名

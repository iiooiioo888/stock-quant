# 7. 數據源

## 7.1 多源容錯架構

系統採用 **主備自動切換** 的數據源策略，每個數據接口配備 2-3 個備選源。

```
請求 → 主數據源 → 成功 → 返回
         ↓ 失敗
       備選源 1 → 成功 → 返回
         ↓ 失敗
       備選源 2 → 成功 → 返回
         ↓ 失敗
       返回錯誤 / 降級數據
```

### 熔斷器

- 連續 5 次失敗 → 觸發熔斷，冷卻 5 分鐘
- 冷卻期間自動跳過該數據源
- 冷卻結束後恢復嘗試

### 速率限制

- AKShare：最低 0.5 秒間隔
- 全局請求限流：可配置每日上限
- 抖動（Jitter）：避免同時大量請求

## 7.2 A 股歷史數據

### 主數據源：Yahoo Finance

- 免費，無需 API Key
- A 股代碼映射：`600519` → `600519.SS`（滬市），`000858` → `000858.SZ`（深市）
- 支持日 K、週 K、月 K

### 備選數據源：AKShare

- 國內 A 股數據最全面
- 限速要求：≥ 0.5 秒/請求
- 支持分鐘 K 線

### 其他備選

- 新浪財經 HTTP API
- 騰訊財經 HTTP API

## 7.3 A 股實時行情

### 東方財富（3 種模式）

| 模式 | 說明 | 緩存 |
|------|------|------|
| 五檔盤口 | 單只股票買賣五檔 | 無 |
| 全量批量 | 批量獲取所有股票實時價格 | 10 秒 |
| HTTP 直連 | 新浪 HTTP 接口 | 無 |

自動降級：東財接口失敗 → 切換到新浪。

## 7.4 全球市場

### 數據源：Yahoo Finance + 新浪全球

支持市場：

| 市場 | 示例代碼 | 說明 |
|------|----------|------|
| 美股 | AAPL, TSLA, MSFT | 納斯達克/紐交所 |
| 港股 | 0700.HK, 9988.HK | 港交所 |
| 日股 | 7203.T, 9984.T | 東京交易所 |
| 歐洲 | SAP.DE, ASML.AS | 歐洲主要交易所 |
| ETF | SPY, QQQ, GLD | ETF 基金 |
| 商品 | GC=F（黃金）, CL=F（原油） | 期貨 |

失敗冷卻：某只股票獲取失敗後，短期內不再重複請求。

## 7.5 加密貨幣

### 數據源：Binance 公開 API

- 無需 API Key
- 支持所有 USDT 交易對
- K 線數據 + 實時行情

```bash
# 支持的交易對
GET /api/crypto/symbols
# BTCUSDT, ETHUSDT, BNBUSDT, SOLUSDT, ...
```

可通過配置開關：`SQ_CRYPTO_ENABLED=true`

## 7.7 Polymarket 預測市場

### 數據源：Gamma API + CLOB API

| API | 用途 |
|-----|------|
| Gamma API | 市場元數據、事件、標籤 |
| CLOB API | 訂單簿、價格歷史 |

- 自帶速率限制和重試機制
- 數據存儲到本地 SQLite 供離線訪問

## 7.8 數據源健康監控

```bash
# 檢查所有外部數據源狀態
GET /api/external-check
```

返回每個數據源的：
- 可用性（是否可達）
- 響應時間
- 最後成功時間
- 熔斷狀態

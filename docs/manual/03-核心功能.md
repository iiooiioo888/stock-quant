# 3. 核心功能

## 3.1 量化回測

### 概述

回測引擎基於 Backtrader 構建，支持 19 種內置策略，針對 A 股特性做了深度適配。

### A 股適配

- **漲跌停過濾** (`LimitFilter`)：自動識別 ±10%（主板）和 ±20%（創業板/科創板）漲跌停，禁止在漲停買入或跌停賣出
- **T+1 規則** (`T1Filter`)：當日買入不可當日賣出
- **滑點模擬**：可配置滑點百分比
- **佣金計算**：可配置佣金率

### 回測指標

| 類別 | 指標 |
|------|------|
| 收益 | 總收益率、年化收益率、月度勝率 |
| 風險 | 最大回撤、年化波動率、VaR 95%、CVaR 95% |
| 風險調整 | Sharpe Ratio、Sortino Ratio、Calmar Ratio |
| 交易 | 交易次數、盈虧比、連續盈利/虧損次數 |
| 回撤 | 最大回撤恢復天數 |

### 進階分析

- **權益曲線分析**：淨值曲線、回撤曲線、月度收益熱力圖
- **蒙特卡洛模擬**：打亂收益率順序 + Bootstrap 重採樣，評估策略穩健性
- **滾動指標**：滾動 Sharpe/Sortino/波動率/回撤（可配置窗口）
- **基準對比**：與滬深 300 對比 Alpha/Beta/信息比率/上行下行捕獲率

### 使用方式

```bash
# CLI
python main.py backtest --code 600519 --strategy macd --cash 100000

# Web API
POST /api/backtest
{
  "code": "600519",
  "strategy": "macd",
  "cash": 100000,
  "start": "2020-01-01",
  "end": "2024-12-31"
}
```

## 3.2 參數優化

### 網格搜索

遍歷策略參數空間的所有組合，適合參數較少的策略。

### Optuna 貝葉斯優化

使用 Tree-structured Parzen Estimator (TPE) 智能搜索最優參數，默認 50 輪試驗。

### Walk-Forward 前進分析

滾動窗口訓練 + 測試，檢測過擬合：
- 默認：750 天訓練 / 250 天測試 / 250 天步進
- 每個窗口獨立優化，評估樣本外表現
- 通過 OOS 性能衰減識別過擬合

### 多目標優化

支持同時優化：Sharpe Ratio、收益率、Calmar Ratio、勝率

### 過擬合防護

- 數據分為 80% 訓練集 / 20% 測試集
- Top N 結果在保留集上重新驗證
- 前端顯示過擬合警告

```bash
# CLI
python main.py optimize --code 600519 --strategy macd --trials 100

# Web API
POST /api/optimize
POST /api/walkforward
POST /api/auto-optimize
```

## 3.3 組合分析

### 支持的組合構建方法（18+ 種）

| 方法 | 說明 |

| 等權重 | 各策略/股票等比例分配 |

| Black-Litterman | 結合市場均衡與主觀觀點 |
| HRP | 層次風險平價 |
| CVaR 優化 | 最小化條件在險價值 |
| 多時間框架 | 結合不同時間尺度的信號 |

## 3.4 實時信號引擎

### 工作原理

1. 對監控股票池中每只股票，運行全部 19 種內置策略
2. 使用 `_LastBarOrderCapture` 分析器，僅捕獲最後一根 K 線的交易信號
3. 根據策略歷史回測 Sharpe 作為權重，計算加權信號強度
4. 5 分鐘快照緩存，避免重複計算

### 信號強度

- 範圍：-100（強烈賣出）到 +100（強烈買入）
- 加權方式：策略歷史 Sharpe Ratio 作為權重
- 並行計算：ThreadPoolExecutor 跨股票並行

```bash
# CLI
python main.py signals

# Web API
GET /api/signals
```

## 3.6 風控系統

### 倉位管理 (`risk_manager.py`)

| 方法 | 說明 |
|------|------|
| 固定比例 | 固定百分比倉位 |
| ATR 基準 | 基於 ATR 計算倉位大小 |
| Kelly 公式 | 基於凱利公式 |
| 波動率目標 | 目標波動率約束 |
| 回撤調整 | 根據當前回撤動態調整 |

### 風險預算

- 單只股票最大風險暴露
- 組合層面風險限額
- 超限時觸發再平衡建議

### 回撤保護

- **Warning** 級別：回撤達閾值，發送警告
- **Critical** 級別：回撤達臨界值，建議減倉
- **Stop** 級別：觸發熔斷，停止交易

### 信號->交易管道 (`risk_pipeline.py`)

```
TradeSignal → RiskCheck → TradeOrder
                         ↘ Rejection (原因: drawdown_stop / budget_exceeded / 
                                       position_too_large / signal_too_weak 等)
```

```bash
# Web API
POST /api/risk/position-size      # 計算倉位
POST /api/risk/budget-check       # 風險預算檢查
POST /api/risk/drawdown-protect   # 回撤保護
```

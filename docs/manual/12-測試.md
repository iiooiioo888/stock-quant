# 12. 測試

## 12.1 概述

- **測試框架**：pytest
- **測試文件**：43 個
- **測試用例**：164+
- **額外工具**：Playwright（可選瀏覽器煙霧測試）

---

## 12.2 運行測試

### 全部測試

```bash
# 安裝開發依賴
pip install -r requirements-dev.txt

# 運行所有測試
pytest tests/ -v

# 運行並顯示覆蓋率（需安裝 pytest-cov）
pytest tests/ -v --cov=src --cov-report=html
```

### 運行特定測試

```bash
# 運行單個測試文件
pytest tests/test_backtest.py -v

# 運行單個測試函數
pytest tests/test_backtest.py::test_basic_backtest -v

# 按關鍵字篩選
pytest tests/ -v -k "auth"

# 按標記篩選
pytest tests/ -v -m "slow"
```

### Playwright 測試

```bash
# 安裝 Playwright
pip install playwright
playwright install

# 運行瀏覽器煙霧測試
pytest tests/test_ui_playwright_smoke.py -v
```

## 12.3 測試配置

`tests/conftest.py` 提供：

- **TestClient fixture**：FastAPI 測試客戶端
- **臨時數據庫**：每個測試會話使用獨立的臨時 SQLite
- **速率限制器重置**：每個測試前重置限流器
- **外部 API Mock**：monkeypatch 外部數據源（資金流、板塊數據等）
- **Session-scoped 數據庫初始化**：整個測試會話共享數據庫

## 12.5 CI 中的測試

GitHub Actions 在每次 push 和 PR 時運行：

```yaml
# Python 3.11 和 3.12 矩陣測試
- pytest tests/ -v --tb=short

# Docker 構建測試
- docker build -t stock-quant .

# 健康檢查測試
- docker run -d stock-quant
- curl --retry 30 --retry-delay 2 http://localhost:8000/api/health
```

# 8. 數據庫設計

## 8.1 概述

- **引擎**：SQLite（WAL 模式）
- **路徑**：`data/stock.db`
- **表數量**：26 張
- **索引數量**：38 個
- **遷移版本**：v3
- **連接管理**：線程本地連接池

### PRAGMA 調優

```sql
PRAGMA journal_mode = WAL;
PRAGMA cache_size = -32000;      -- 32MB 緩存
PRAGMA mmap_size = 268435456;    -- 256MB 內存映射
PRAGMA busy_timeout = 5000;      -- 5 秒等待
PRAGMA synchronous = NORMAL;
```

## 8.3 索引

系統定義了 38 個索引，覆蓋所有常用查詢路徑：

```sql
-- 示例索引
CREATE INDEX idx_kline_code_date ON daily_kline(code, date);
CREATE INDEX idx_backtest_code ON backtest_results(code);
CREATE INDEX idx_backtest_strategy ON backtest_results(strategy);
CREATE INDEX idx_signal_code ON signal_log(code);
CREATE INDEX idx_task_status ON task_log(status);
CREATE INDEX idx_task_type ON task_log(task_type);
CREATE INDEX idx_sector_name ON sector_data(sector_name);
CREATE INDEX idx_capital_flow_code ON capital_flow(code, date);
CREATE INDEX idx_stock_universe_market ON stock_universe(market);
```

## 8.4 遷移系統

版本化遷移，定義在 `src/core/database/migrations.py`：

| 版本 | 說明 |
|------|------|
| v1 (001_baseline) | 基線 Schema，所有表和索引 |
| v2 (002_legacy_columns) | 舊版列補丁 |
| v3 (003_recover_stale_tasks) | 恢復卡住的任務 |

遷移在應用啟動時自動執行（`bootstrap.py`）。

# 6. 前端說明

本項目包含 **兩套完整的前端架構**，共存於同一倉庫中。

## 6.1 頁面路由

| URL | 頁面 | 說明 |
|-----|------|------|
| `/` | Landing 頁 | 產品落地頁（`home.html`） |
| `/app` | Pro 工作站 | 新版主應用（`app.html`） |
| `/admin` | 管理後台 | 用戶/系統管理（`admin.html`） |
| `/legacy/` | 舊版 SPA | 經典 16 Tab 界面（`legacy/index.html`） |

### 模塊模式

全局單例模式，每個模塊暴露 `init()` 和 `load()` 方法：

```javascript
// 全局對象
window.App = { init(), load(), ... }
window.Api = { get(), post(), ... }
window.Dashboard = { init(), load(), ... }
```

### API 客戶端特性（`api.js`，639 行）

- Token 管理（localStorage `sq_token`）
- GET 緩存帶 TTL（按端點配置 `_cacheTtl`）
- 請求去重（`_inflight` map）
- 長任務互斥（`_exclusive` keys）
- 防抖 GET
- 429 處理
- 認證頭注入

### 模塊模式

IIFE 註冊到全局命名空間：

```javascript
// 頁面模塊
(function() {
    const mod = {
        init() { ... },
        render() { ... },
        destroy() { ... }
    };
    window.StockQPro = window.StockQPro || {};
    window.StockQPro.pages = window.StockQPro.pages || {};
    window.StockQPro.pages['dashboard'] = mod;
})();
```

### UI 組件庫（`pro/ui/index.js`）

純原生 JS DOM 構建器：

```javascript
const { h, clear, mount, on } = window.StockQPro.UI;

// 創建元素
const card = h('div', { class: 'card' }, [
    h('h3', {}, '標題'),
    h('p', {}, '內容')
]);

// 掛載到 DOM
mount(document.getElementById('app'), card);
```

## 6.7 暗色/亮色主題

Legacy SPA 支持暗色和亮色兩套主題，通過 CSS 變量系統切換：

```css
:root {
    --bg-primary: #0d1117;
    --bg-secondary: #161b22;
    --text-primary: #e6edf3;
    /* ... */
}

[data-theme="light"] {
    --bg-primary: #ffffff;
    --bg-secondary: #f6f8fa;
    --text-primary: #24292f;
    /* ... */
}
```

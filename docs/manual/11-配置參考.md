# 11. 配置參考

所有配置項使用 `SQ_` 前綴，可通過環境變量或 `.env` 文件設置。

## 11.1 應用配置

| 變量 | 類型 | 默認值 | 說明 |
|------|------|--------|------|
| `SQ_APP_NAME` | str | stock-quant | 應用名稱 |
| `SQ_APP_VERSION` | str | 1.1.0 | 版本號 |
| `SQ_DEBUG` | bool | false | 調試模式 |
| `SQ_WEB_HOST` | str | 0.0.0.0 | 監聽地址 |
| `SQ_WEB_PORT` | int | 8000 | 監聽端口 |
| `SQ_WEB_WORKERS` | int | 4 | Uvicorn 工作進程數 |

---

## 11.15 策略參數配置

每個內置策略都有可配置的默認參數：

| 變量格式 | 說明 |
|----------|------|
| `SQ_STRATEGY_DUAL_MA_FAST` | 雙均線快線周期 |
| `SQ_STRATEGY_DUAL_MA_SLOW` | 雙均線慢線周期 |
| `SQ_STRATEGY_MACD_FAST` | MACD 快線 |
| `SQ_STRATEGY_MACD_SLOW` | MACD 慢線 |
| `SQ_STRATEGY_MACD_SIGNAL` | MACD 信號線 |
| `SQ_STRATEGY_RSI_PERIOD` | RSI 周期 |
| `SQ_STRATEGY_RSI_OVERSOLD` | RSI 超賣閾值 |
| `SQ_STRATEGY_RSI_OVERBOUGHT` | RSI 超買閾值 |
| `SQ_STRATEGY_BOLLINGER_PERIOD` | 布林帶周期 |
| `SQ_STRATEGY_BOLLINGER_DEV` | 布林帶標準差倍數 |
| `SQ_STRATEGY_TURTLE_ENTRY` | 海龜入場周期 |
| `SQ_STRATEGY_TURTLE_EXIT` | 海龜出場周期 |
| ... | （共 19 個策略的參數） |

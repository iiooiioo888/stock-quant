快速開始
  1. 預載數據python main.py seed 或從數據中心下載日 K
  2. 選策略在策略庫挑選內建策略，或創建自定義策略
  3. 跑回測輸入代碼與參數，提交後在任務面板查看進度
  4. 上線盯盤加入自選、設置預警，交易時段實時監控

技術架構
  • FastAPI REST + WebSocket 實時推送
  • SQLite 本地 WAL 數據庫 + 版本化遷移
  • Yahoo 主行情源，AKShare 備選降級
  • Redis 可選跨進程結果緩存（Docker）
  • 任務隊列 回測 / 優化 / 組合異步執行

進階功能（數據中心、Polymarket、調度器、組合回測等）已整合至 Pro 工作站，可用 Cmd+K 快速跳轉。
